# Battle City Clone — Last Version

Клон классической Battle City на Unity: разрушаемые стены, система жизней, бонусы, ИИ-враги.

 Особенности версии
- "Разрушаемые стены": кирпичные тайлы исчезают при попадании, коллизия обновляется через `LevelDamageController`.
- "Механика жизней": игрок возрождается при потере жизни (`LivesComponent`), ИИ-танки умирают сразу.
- "Бонусы": подбор бонусов (щит, звезда, лопата и др.) с разными эффектами.
- "Физика и коллизии": `CompositeCollider2D`, `TilemapCollider2D` на стенах; корректная обработка `OnTriggerEnter2D`.
- "Анимации": взрывы, вспышки, эффекты попаданий.

 Как запустить
1. Открыть проект в Unity.
2. Открыть сцену `Assets/Scenes/SampleScene.unity`.
3. Нажать Play.

 Технологии
- Unity 6
- C#
- Tilemap + Colliders
- Пул объектов (частично: Пули и ИИ)

 Статус
Версия: Last Version (актуальная). Старые версии лежат в отдельных репозиториях как архив.
